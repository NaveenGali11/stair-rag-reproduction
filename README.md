# Independent STAIR Reproduction

## Goal
Test whether a Table-of-Contents-aware retriever (STAIR) improves section retrieval over BM25, dense vector retrieval, and DSI-style parametric retrieval.

## Reproduction status
Independent reconstruction from the paper and public textbooks. The authors' anonymous release is unavailable.

## First experiment
One book, one validated ToC tree, and one inspectable query-to-leaf example before training any model.
